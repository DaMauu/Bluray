# 快速上手

三分钟从零到第一次完整跑通。只写必要步骤，细节见 [使用手册](GUIDE.md)。

---

## 0. 前置条件

- 浏览器已安装 Tampermonkey（或 Violentmonkey）
- 已登录源站与目标站
- 可选：qBittorrent WebUI 地址与账号（需要自动推种时）

## 1. 安装脚本

打开 [`legacy/pt-bluray-assistant-v0.0.0.32.user.js`](../legacy/pt-bluray-assistant-v0.0.0.32.user.js) → 点 `Raw` → 在 Tampermonkey 安装页确认。

刷新任意受支持站点，页面右上角出现「原盘转载面板」面板即安装成功；控制台应有一行 `[PT助手] v0.0.0.32 已注入 @`。

## 2. 配置（只需填一次）

点面板「⚙️ 面板设置」：

| 分组 | 必填 | 说明 |
|---|---|---|
| qBittorrent | 推种才填 | WebUI 地址、用户名、密码；分类填目标分类名 |
| 源 A 站 / 目标 B 站 | 是 | 默认自动识别当前站点；跨站搬运时手动指定 |
| 图床 | 默认开 | 截图自动转存目标站图床，需浏览器已登录目标站 |
| 截图数量上限 | 默认 15 | 简介里最多放几张截图 |
| 副标题主演数 | 默认 3 | 副标题里保留几位主演 |
| 词库有效期 | 默认 720h | 命中词库的条目不重复请求目标站 |

保存后关闭。

## 3. 跑通一次

1. **搜索预设**：把当前站筛选锁成「电影 / 蓝光原盘」，不再手动点条件。
2. **拉取数据**：审核当前页 → 自动翻页 → 批量查重。日志逐页打印命中数与累计条数。
3. 看列表徽标：`B站已有原盘` 为冲突，`B站暂无此原盘（可发）` 进待发队列。
4. **转种**：队列里点某条的「🚀 转种」，脚本取 BDInfo、截图、豆瓣简介，转存图床，打开目标站上传页自动填单。
5. **全套**：想一步到位就点「⚡ 全套」，等于转种 + 推 qB。

人工检查上传页无误后，自己点发布。

## 4. 出问题先看这里

| 现象 | 处理 |
|---|---|
| 面板没出现 | 看控制台是否注入；确认站点在支持列表 |
| 日志刷「429 / 登录态失效」 | 目标站限流，脚本已自动停；等几分钟再点「拉取数据」，会从断点继续 |
| 队列里有冲突但你认为可发 | 点该行「🔁 二查」强制复查一次 |
| 图片是小图 | 看日志「原图确认」行的宽度；若源站本身只有小图则无解 |
| 标题被站点改写 | 确认面板版本 ≥ 0.0.0.15（标题守卫） |
