## 一、面板导览

面板分左右两列，四个方块高度对齐。

### 左列

| 区域 | 作用 | 说明 |
|---|---|---|
| 副标题 | 生成/编辑副标题 | 可手改；「🔄 重新生成」会按当前 BDInfo 与豆瓣信息重排 |
| 简介 | 生成/编辑简介 | 含豆瓣文本、BDInfo、截图 BBCode；右上「📋 复制全部」 |
| ⚡ 抓当前页 | 只处理当前详情页 | 提取 BDInfo、截图、IMDb，不查重 |
| 📋 复制副标题 | 复制到剪贴板 | 发布页可手动粘贴 |
| ✅ 确认发布 | 走完整转种流程 | 两次确认，防误触 |

### 右列

| 区域 | 作用 |
|---|---|
| 信息卡 | 转载站 / 发布站 / 运行通道（网页模式或 API 模式）/ 下载器（地址与端口部分掩码） |
| 实时运行日志 | 全流程日志，可划选复制 |
| ⚙️ 面板设置 | 站点、qB、图床、词库、排版参数 |
| 📀 搜索预设 | 把站点筛选锁定为「电影 + 蓝光原盘」，并清掉促销、编码等干扰条件 |
| 🚀 拉取数据 | 审核当前页 → 翻页 → 批量查重；运行中按钮变「⏸ 暂停」 |
| 🔁 二查 | 只重查当前页标着「可发」的种子，逐条强制刷新 |
| ⏸ 断点暂停 | 立即停住，名单、页号、队列全保留 |
| 👁️ 显示全部 | 在「显示全部」与「隐藏不可发」之间切换 |

## 二、什么算合格原盘

审核阶段逐条判断，命中任一排除条件即跳过：

- 标题/标签含 `x264`、`x265`、`HEVC`（重编码）、`WEB`、`HDTV`、`Remux`、`Encode`
- 介质为 DVD / HD DVD 以外的非蓝光源
- 标记 `DIY`、`禁转`、`限转`（按站点标签与文本双重判断）
- 体积明显异常（如 < 15 GB 的“原盘”）

同时记录每条的 IMDb、体积、是否 4K，供查重与填单使用。

## 三、查重与词库

### 查重顺序

1. IMDb ID（源条目有 IMDb 时优先）
2. 西部片名（`AXA` 之前那一段）
3. 发行名里的 `AKA` 原名
4. 完整片名（截到年份）

命中后用两条硬条件确认是同一张盘：**4K 属性一致** 且 **体积差 ≤1%**。避免同名不同版被误判。

### 结果标记

| 徽标 | 含义 |
|---|---|
| `B站已有原盘 (XX.XG) [复核]` | 目标站已有同盘，进冲突 |
| `B站暂无此原盘 (可发)` | 可进入待发队列 |
| `B站已有原盘（已存）[复核]` | 词库命中，本次未发请求 |

### 词库

- 按目标站分区存储，32 个分片，默认 720 小时有效。
- 命中词库的条目直接出结论，不再请求目标站。
- 面板底部：`🔄 恢复`（零请求重绘徽标）、`查看`、`导出`、`导入`、`清空`。
- 旧规则得出的结论会继续生效，可用「🔁 二查」逐条强制刷新。

## 四、断点与暂停

- 「⏸ 断点暂停」= 立即请求停止；当前这一步结束后停住。
- 断点保存三样东西：名单（种子条目）、抓到第几页、已查过的种子 id。
- 下次点「🚀 拉取数据」，翻页从上次页号继续，查重跳过已查条目。
- 只有真正翻到最后一页才标记「完成」；中途停下会保留断点。
- 页面地址变化、重新登录不影响断点续用。

## 五、转种流程

点「🚀 转种」或「⚡ 全套」后：

1. 拉取源站详情页，解析 BDInfo、MediaInfo、IMDb、豆瓣链接。
2. 生成副标题：`中文名 | 版本 | 导演:X | 主演:A / B / C | [语言] | [字幕]`。
3. 生成简介：豆瓣文本 + `[hide=bdinfo]` 表格 + 截图。
4. 截图处理：合并所有描述容器 → 还原缩略图后缀 → 解包图片代理 → 候选地址逐个测宽取最大 → 转存图床 → 返图尺寸复核（变小则回退原链）。
5. 拉取 `.torrent` 二进制，改 tracker 与 source 标记。
6. 打开目标站上传页：塞种子文件、填标题/副标题/IMDb/豆瓣/简介、勾标签、选类型/分辨率/地区。
7. 标题守卫：标题只写一次，检测到人工输入立即放手，避免与站点自动回填打架。

发布前请自己核对上传页，脚本不会替你点发布。

## 六、qBittorrent 推送

- 面板「📥 qB」或队列里的「📥qB」推送单条，「⚡ 全套」= 转种 + 推 qB。
- 推送前会创建分类（若不存在），推送后核对分类，不一致则补设。
- qB 密码只存在脚本管理器本地，仅发送到你在设置里填的 WebUI 地址。
- 日志中的下载器地址做了掩码（`185.150.*.*:80**`）。

## 七、设置项详解

| 设置 | 默认 | 建议 |
|---|---|---|
| qB 分类 | 空 | 填目标分类名，留空则不加分类 |
| 查重延时 | 2500ms（下限 4000ms） | 站点容易限流时调高 |
| API 连拉页数 | 仅当前页 | UNIT3D 站点填了 API Key 时可加大 |
| 词库有效期 | 720h | 想更准就缩短，想更快就拉长 |
| 词库上限 | 20000 | 一般不用改 |
| 副标题主演数 | 3 | 按发布习惯 |
| 截图上限 | 15 | 图多会拖慢转种 |
| 自动转存图床 | 开 | 没登录 PterClub 时会提示 |
| M-Team 自动拉取 | 开 | 预设完成后是否自动开始拉取 |

## 八、常见问题

**面板没出现？**
控制台看 `[PT助手] vX 已注入 @`。没有则是脚本未运行或站点不在 `@match` 列表。

**疯狂 429 / 被踢下线？**
脚本检测到登录页或 403 会立即停并保留断点。等几分钟，重新登录后再点「拉取数据」，从断点继续。不要连点。

**上传时提示「同种子已存在」？**
目标站按种子文件与标题判重。先点该行「🔁 二查」，再确认目标站是否真有同盘（可能是原名条目）。

**标题被改回英文/带年份？**
确认版本 ≥ 0.0.0.15；该版本起种子文件名与标题都用源站原文，并有标题守卫。仍被改的话是站点在文件注入后回填，可在上传页手动改回，脚本不会再覆盖。

**图片还是小图？**
看日志「原图确认 N/M：…（宽度px）」。宽度够大说明源站文件本身如此；不足 700px 会 WARN 提示源站只有缩略图。

**能同时开多个站点吗？**
可以开多个标签页，但同一时间只建议跑一个「拉取数据」，避免同一目标站并发触发限流。

## 九、安全与合规

- 不保存任何站点账号密码；图床登录只走浏览器单点登录。
- 所有请求以你的登录态发出，等同手动操作，请自行控制频率。
- 仅供个人在已获授权的私有 PT 站之间搬运；转种前确认无禁转、无重复。
