# AI 上下文与开发要求（future 分支）

给接手这个分支的 AI / 协作者的说明书。先读本文件，再读根目录 `README.md`。

---

## 1. 项目是什么

一个 Tampermonkey 油猴脚本，作用是**在私有的高清 PT 站之间搬运未处理过的蓝光原盘**：

1. 在源站 A（如 Blutopia）的列表页/详情页读取种子信息，过滤掉重编码、DVD、DIY、禁转；
2. 去目标站 B（默认 PTerClub 猫站）按 IMDb、片名、`AKA` 原名多关键词查重；
3. B 站没有的进待发队列；
4. 点“转种”时提取 BDInfo、截图、豆瓣简介，把截图转存猫站图床，然后打开 B 站上传页自动填表；
5. 也可以把 `.torrent` 推给 qBittorrent 并自动设置分类。

支持页面结构：NexusPHP、UNIT3D、Gazelle、f3nix（BeyondHD）。

## 2. 代码在哪

- 本分支只有单文件版：`legacy/pt-bluray-assistant-v0.0.0.17.user.js`（6000+ 行，`(() => { ... })()` IIFE，`var` + 函数声明，无构建步骤）。

- `main` 上的 `src/`、`dist/` 是**另一条线**（模块化 + esbuild），本分支不修改、不合并。

## 3. 必须遵守的硬规则

1. **版本号从 `0.0.0.1` 起，每次更新 +0.0.0.1**（0.0.0.2、0.0.0.3 …），四段式只增不减，作废的号不回收。每次改动新建 `legacy/pt-bluray-assistant-v<版本号>.user.js`，旧版本永不覆盖、永不删除。
2. 改版本必须**三处同步**：`@version`、面板标题 `转种与调度中枢 (vX.Y.Z)`、启动日志 `[PT助手] vX.Y.Z 已注入 @`。
3. 提交前 `node --check` 通过，并跑完 `docs/DEVELOPMENT.md` 第 5 节列出的全部回归。
4. **不存任何站点账号密码**；图床登录只走浏览器 SSO 按钮流程。
5. **不自动点击发布**；发布前复核发现 B 站已有原盘时必须拦下。
6. 恢复类操作（恢复徽标、读词库）**零网络请求**。
7. 不要清空用户词库、不要删除 `pt_batch_checkpoint`，除非用户明确要求。

## 4. 关键行为（改代码前必须确认）

| 项目 | 规则 |
|---|---|
| 面板信息卡 | 转载站/发布站只显示站名（去架构、去中文名、去模式图标）；运行通道只显示网页模式或 API 模式；下载器地址与端口部分掩码 |
| 标题 | 源站固定位置原文：详情页 `h1.torrent__name`、列表行 `a.torrent-search--list__name`；一字不改；只填一次；用户手动改过就放手 |
| 副标题 | `中文名 \| 版本 \| 导演:X \| 主演:A / B / C \| [语言] \| [字幕]` |
| 英字 | 只看 BDInfo `Subtitle:` 行是否有 English；绝不用裸 `ENG` 全文匹配 |
| 中字 | BDInfo 有 Chinese/Mandarin/CHS/CHT，或简介出现“中字/中文” |
| 截图 | 优先二进制上传（先下原图再传，避免图床按 URL 抓取时压缩）；BBCode 支持 `[img=400]` 与 `[url=原图]` 包裹，优先取 url 里的原图；合并所有描述容器；还原 `.md/.th/_thumb/-400x225/?w=400` 与 `wsrv.nl` 类代理；按原图去重；图床返图变小回退原链 |
| 查重 | IMDb/片名 → `AKA` 原名 → 完整片名；发布前强制复核一次 |
| 限流 | 查重间隔 ≥4 秒，每 10 条歇 30 秒，429 退避 60 秒；发现登录页/403 立即停并保留断点 |
| M-Team | 预设只锁 `電影/BluRay`（cat-421），不设促销；每页 2–3.2 秒、每 20 页歇 12 秒 |

## 6. 已知坑（别重复踩）

1. 猫站会按**种子文件名**回填上传页标题 —— 所以文件名必须与源站标题一致，并在挂载种子后守一段标题。
2. 词库有 720 小时缓存，旧规则得出的“可发”结论仍然生效 —— 只有发布前复核能兜住。
3. UNIT3D 的 BDInfo 可能是字段粘连的 HDDVDinfo（`Disc Size:…bytesPlaylist:`），不解析，手工替换。
4. M-Team 列表是前端渲染，服务端抓 HTML 拿不到行，必须在页面内翻页抓。
5. 目标站请求过快会被踢下线，脚本现在会检测登录页并立即中止。
