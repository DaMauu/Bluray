# PT 原盘转载发布与智能查重助手

一个 Tampermonkey 单文件脚本，用来把**未处理过的蓝光原盘**从一个 PT 站搬到另一个 PT 站：读源站列表、剔掉重编码/DVD/DIY/禁转、去目标站查重、把可发的排进待发队列，再从源站详情页取 BDInfo、截图、豆瓣简介，自动填好目标站的上传表单。

- 当前版本：`legacy/pt-bluray-assistant-v0.0.0.27.user.js`
- 分支：`future`（单文件版；与 `main` 的 `src/` 模块化版本互不合并）
- 作者：大肥鱼（DeepSeek 鲸鱼小人）
- 支持页面：NexusPHP、UNIT3D、Gazelle、f3nix（BeyondHD）

---

## 它做什么

在列表页或详情页右上角挂一个面板，几个动作：

| 动作 | 说明 |
|---|---|
| 拉取数据 | 审核当前页 → 翻页抓全站（或走 UNIT3D API）→ 批量查重，可发的进待发队列 |
| 二查 | 只重查当前页标着「B站暂无此原盘（可发）」的种子，逐条强制刷新，不点不跑 |
| 断点暂停 | 立刻停住，名单、页号、队列全部保留，下次接着跑 |
| 转种 | 取 BDInfo / 截图 / 豆瓣简介，截图转存图床，打开目标站上传页自动填表 |

配套能力：

- 本地词库按目标站分别存，默认 720 小时有效，命中就不再请求目标站。
- 断点记录抓取页号与已查种子，换页面地址也不作废。
- 截图支持缩略图还原、代理地址解包、按候选地址测宽取最大原图；上传后还会再比一次尺寸。
- 标题严格取源站标题原文，只填一次；种子文件名同源站标题，避免目标站按文件名改写标题。

## 安装与更新

1. 打开 `legacy/pt-bluray-assistant-v0.0.0.27.user.js`，点 Raw，Tampermonkey 会提示安装。
2. 更新时先在 Tampermonkey 里删掉旧版本，再装新文件；刷新页面后确认面板标题显示新版本号。
3. 桌面只保留最新一版，旧版本移入 `C:\Users\wiii\Desktop\PT助手-历史版本\`。

## 关键行为约定

1. **标题**取源站固定位置原文（详情页 `h1.torrent__name`、列表行 `a.torrent-search--list__name`），一字不改，只在为空时填一次；手动改过就不再动。
2. **副标题**格式：`中文名 | 版本 | 导演:X | 主演:A / B / C | [语言] | [字幕]`，主演数量可配。
3. **英字**只看 BDInfo 的 `Subtitle:` 行是否出现 English；**中字**看 BDInfo 语言或简介里的“中字/中文”。
4. **截图**按候选地址（原链、去 `.th/.md`、去尺寸后缀、`thumbs→images`、图片站查看页）逐个测宽，取最大；测不到宽度时也不退回缩略图。
5. **查重**按 IMDb/片名 → `AKA` 原名 → 完整片名依次尝试；目标站返回登录页或 403 立即中止并保留断点。
6. **限速**：查重间隔 ≥4 秒，每 10 条歇 30 秒；M-Team 翻页每页 2–3.2 秒、每 20 页歇 12 秒。
7. 不存储任何站点账号密码，图床登录只走浏览器单点登录。

## 开发

**版本号规则**：从 `0.0.0.1` 起，每次更新 +0.0.0.1（`0.0.0.2`、`0.0.0.3` …），四段式只增不减，作废的号不回收。每次改动新建文件，旧版本永不覆盖。

**提交前必须**：

```powershell
node --check legacy\pt-bluray-assistant-v0.0.0.27.user.js
```

并跑完全部回归（Node，位于 `%TEMP%\pt_*_test.js`）：

```
pt_cast_test        pt_title2_test      pt_label_test       pt_shot_test
pt_auth_test        pt_aka_test         pt_imgverify_test    pt_info_test
pt_decl_test        pt_pixhost_test     pt_mteam_test        pt_mteam_preset_test
pt_mteam_crawl_test pt_err_test         pt_worker_test       pt_qb_test
```

**改版本必同步三处**：`@version`、面板标题 `转种与调度中枢 (vX)`、启动日志 `[PT助手] vX 已注入 @`。

## 已知问题

- 目标站会按种子文件名回填标题：目前用“文件名=源站标题 + 标题守卫”压制，需持续观察。
- 词库里旧规则得出的“可发”结论仍在有效期内，靠发布时的人工确认与「二查」兜底。
- 字段粘连的 HDDVDinfo（`Disc Size:` 与 `Playlist:` 粘成一行）不解析，需手工替换。
- 图床若把长图压到 400px，脚本会回退原链；这种情况下简介里就是源站原图链接。
